# 粮仓智改 Web/PWA 展示版

这是从 `软件8.24/粮仓智改10.py` 独立迁移出的响应式网页版本。原 Python 文件没有被修改。

## 直接使用

电脑可双击 `run_web_app.bat`，浏览器会打开 `http://localhost:8080`。手机和电脑也可以通过 GitHub Pages 正式 HTTPS 链接直接访问，并可安装为 PWA 应用。

## 当前功能

- 响应式电脑/手机布局；
- 参数输入与校验；
- 24小时三工况动态计算；
- 温度、热量、设备耗电、总耗电、费用及回收期图表；
- 经济性汇总表；
- CSV、TXT、JSON 导出；
- 浏览器打印/另存为 PDF；
- PWA 安装和离线缓存。

## 模型一致性

`model.js`保留了 Python 原版的默认参数与计算公式。Web迁移没有主动修正原模型公式。
