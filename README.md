# 粮仓智改 · 23版 Web/PWA

[打开评估平台](https://sascha-teng.github.io/granary-energy-app/)

河南平房仓双层通风屋面与土壤源嵌管辅助降温的比赛展示用简化模型。沿用既有网页的布局和响应式导航，以粮仓智改23版的小修模型计算。

## 功能

- 在相同仓内空气设定温度下比较原屋面、双层通风、双层＋土壤源嵌管三个方案。
- 24小时仓顶等效节点温度、传入热量、制冷／风机／水泵电耗及正负节能率。
- 两套改造方案分别设置年度维护费率，比较年净收益与静态回收期。
- 参数编辑、CSV／TXT／JSON导出、报告复制、打印、手机响应式展示与PWA离线使用。
- 计算全部在浏览器本机完成，无需后端。

## 默认结果

屋面1000㎡、仓内空气23℃、土壤源供水17℃、电价0.65元/kWh、90个模拟高温日。

| 日总耗电/kWh | 325.96545 | 241.72904 | 243.31966 |
| 节电率/% | — | 25.84213 | 25.35416 |
| 年维护费/元 | 未单列 | 1500 | 2200 |
| 年净收益/元 | — | 3427.83 | 2634.78 |
| 静态回收期/年 | — | 29.17 | 83.50 |

此默认工况下，嵌管进一步降低仓顶峰值，但未比双层方案进一步节电，不能宣称经济性最优或快速回本。

## 模型边界

统一的是仓内空气温度，不是整仓粮温。冷负荷含屋面、墙体和固定粮堆表层换热，未完整考虑渗透、呼吸热与整仓初始降温。气象为合成高温日，年收益为该日乘运行天数的估算。土壤源定温供水为假设，未校核地埋管持续供冷能力，造价和维护费率为估算输入。

沿用23版的小时更新顺序：气象与热流取步初，记录的仓顶温度为步结束值；曲线不是粮温或实测内表面温度。
